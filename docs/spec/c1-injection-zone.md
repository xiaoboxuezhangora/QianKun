# C1 注入区协议

## 目的

C1 注入区用于在用户已有 instructions 文件中标记乾坤袋可管理的内容边界。W1 只定义协议和解析行为，避免把标记区外的用户原文误认为乾坤袋注入内容。

## 标记格式

注入区必须使用固定 HTML 注释标记：

```md
<!-- QIANKUN:START -->
乾坤袋生成或维护的内容
<!-- QIANKUN:END -->
```

解析器只提取 `START` 和后续第一个 `END` 之间的内容。标记外文本保持用户原状，不进入乾坤袋注入内容。

## 幂等更新原则

后续实现自动更新时，只能替换已有注入区内部内容，不应重排、删除或格式化标记区外的用户文本。多次运行同一输入应得到一致输出，除非注入内容本身发生变化。

## 文件读取约定

W1 提供文件级读取入口，但只读取项目根目录下的 `AGENTS.md` 和 `CLAUDE.md` 注入区。文件不存在时返回空结果，不报错；文件读取失败、标记不完整或孤立结束标记时，错误信息必须带上文件路径，方便定位。

文件级读取仍只提取 `<!-- QIANKUN:START -->` 到 `<!-- QIANKUN:END -->` 之间的内容。标记外文本保持用户原状，不作为乾坤袋注入内容。W1 不自动改写 `AGENTS.md` 或 `CLAUDE.md`。

## 错误处理

- 无注入区：返回空结果，不报错。
- 单个注入区：返回该区间内内容。
- 多个注入区：按文档出现顺序返回所有区间。
- 缺失 `<!-- QIANKUN:END -->`：返回清晰错误，指出起始位置和缺失的结束标记。
- 孤立 `<!-- QIANKUN:END -->`：返回清晰错误，避免误判用户内容。

## 非目标

W1 不自动修改用户的 `AGENTS.md`、`CLAUDE.md`、`.github/copilot-instructions.md` 或其他 instructions 文件；不做 InstructionsLinter；不生成注入内容；不实现 Memory Index、UsageMeter、MCP server 或 IDE 插件真实逻辑。
